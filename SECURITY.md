# Security reporting

During public alpha, best-effort security corrections target the latest public prerelease. No response-time or remediation guarantee is offered. This unpublished candidate does not establish a supported release or a qualified update/rollback path.

Report vulnerabilities through the repository's [private vulnerability-reporting route](https://github.com/DigitalSteel/CollectiGen/security/advisories/new). If it is unavailable, open a minimal public issue asking the maintainer to restore a private channel, without describing the vulnerability.

Include the affected version, platform, concise impact and smallest safe reproduction. Do not put private images, Image Knowledge, local paths, credentials, signing material or unredacted reports into a public issue or source commit.

Keep test copies and backups during evaluation. Signed release metadata, when supplied, proves integrity against the reviewed key; it is not a Windows publisher signature or a promise that security software will allow launch. Follow [startup limits](README.md) and [prerequisite guidance](WINDOWS_PREREQUISITES.md).
