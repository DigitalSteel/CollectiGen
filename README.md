# CollectiGen Media Organizer

**Media Organizer 0.7.0-alpha.2** is a local unsigned source candidate. It retains
Organizer's published 0.7.0 image workflows and adds keyboard return from
Encyclopedia details without losing the selected row or view context. Generate
and Training execution belong to Suite Manager.

See [candidate release notes](RELEASE_NOTES.md). No alpha.2 download or signed
release is published by this source change. The [prior published alpha.1](https://github.com/DigitalSteel/CollectiGen/releases/tag/collectigen.media-organizer/v0.7.0-alpha.1)
remains a separate artifact.

Export reusable Tag names/aliases, Characters and reviewed Outfit prompt choices with **Knowledge > Prompt Catalog**, then **Knowledge > Prompt Choices > Export Prompt Catalog for Generate**. Review and save a new export; import it in **Suite Manager a.0.7.6 or newer > Generate > Use Organizer Prompt Catalog**. The export excludes images, library/model paths and unreviewed Outfit text. Existing rule repair, Undo and Copy recovery remain included.

## Start

Extract the complete ZIP into a new writable folder, keep its contents together,
and run **Start_MediaOrganizer.bat**. Retain your previous package and separate
profile, image and catalog backups. Windows may report an unknown publisher:
CollectiGen signs update metadata, while the executable has no Authenticode signature.

Use **Suite Manager > Applications > Get or update Media Organizer** to find the latest compatible signed release. Review the version and confirm installation. Module updates do not require rebuilding Manager.

## Work across components

- In **Ingest > Add Images > Review Manager Result**, select a verified image or
  video receipt and review the source-preserving copy. Imported evidence remains
  unreviewed. For a trimmed video, also select its original Manager video receipt.
- Prepare captions, collections and Training packages in Dataset. Export a saved
  Dataset draft for **Manager > Training > Review a Dataset Draft** when you want
  to review the plan before building data.
- Prepare offline image/video drafts or reviewed Character/Outfit setups in
  Organizer, then import them in Manager. Organizer does not start a generator
  or training runtime.

Copy and recovery preserve exact file identity and family bytes, retain reviewed Manager results for explicit Retry after busy file work, and provide the existing copied-family Recycle action.

In a.0.6.0, open **Setup > AI Tools & Models > LM Studio Connection** to save a local HTTP address and preferred model key. **Refresh Models** reads the reported list; choose a key, then **Save Connection** separately. Refresh does not load models, change the current AI provider or analyze images. Credential entry and image analysis through LM Studio are not included. Existing rule repair, exact Restore and image-editor corrections remain included.

The exact a.0.6.0 package passed generated loopback Refresh, selection, separate Save, Cancel with physical cleanup, fresh-process preference reopen and normal Close offscreen. Reopen made no network requests. The existing missing-ExifTool installer prompt was explicitly declined; metadata writing was not qualified by this run. Prior a.0.5.8 is authenticated for recovery, and existing transaction recovery proof is retained. Actual installed rollback, real libraries, an actual LM Studio server, model or trainer execution and full suite parity are not claimed.
