The unpublished 0.6.0 Alpha candidate is being reviewed across its implemented Manager surfaces. This is a source/evidence inventory, not blanket native acceptance. All tests use synthetic settings and catalogs. No live library, publication, signing or new component authority is included.

## UI corrections under verification

- Reader recovery has its own Recovery disclosure. The installed transaction's authenticated journal names the previous Reader version; a first installation instead says Undo installation and explains that no Reader will remain selected. Confirmation is bound to the displayed installation snapshot and rechecked before recovery. Catalogs/images are preserved by the original transaction and connection writer.
- Normal portable entry restores the last named page and window geometry from its explicitly admitted Manager INI. Preferences save only after ordinary Close is permitted. Unknown INI keys remain; application connections stay in their existing JSON authority. Demo/default source windows do not read a personal UI profile. Qt bounds restored geometry for a changed display.
- Applications hides repository/GGUF commands when their original host is unavailable. This grants no new model execution or repository access.

Owners: `core/encyclopedia_installation.py::EncyclopediaInstallation`, `suite_core/manager/encyclopedia_acquisition_ui.py::EncyclopediaAcquisitionPanel`, shared `suite_core/manager/organizer_acquisition_ui.py::OrganizerAcquisitionPanel`, `suite_core/manager/ui_preferences.py::ManagerUiPreferences`, `suite_core/manager/__main__.py::main`, and `suite_core/manager/window.py::create_window`. - Servers refresh shows shared indeterminate activity and elapsed time until original worker retirement, including after Cancel. Its idle guidance names the actual Refresh this computer command.
- Usable Reader/Ollama cards precede development cards; contextual Databases guidance clears on unrelated navigation while genuine errors remain.
- Tag Database previews lead with current/provided content and verified change counts. Version provenance remains one disclosure away, readable tag/field labels retain stable IDs and protected edit evidence, and original Apply/recovery authority is unchanged.

- Diagnostics uses the shared measured compact buttons and follows the selected export category in its preview. ZIP selection and export authority remain unchanged.
