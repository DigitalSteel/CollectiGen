# Media Organizer a.0.4.5 — evaluation prerelease

Compatibility version: `0.4.5-alpha.1`. This is an independent Windows x64 Organizer package, not a complete suite.

## Supported scope

- Local image organization, gallery and Dataset workflows, manual image descriptions/tags, and JSON/TXT metadata workflows.
- Guarded image moves and preservation of original image bytes, generator evidence and unknown metadata fields in the qualified sample workflow.
- Guided Setup: Library locations, optional AI setup, Preferences and defaults, Review and finish. Finish saves choices without opening a library or starting a scan. Previously saved choices are retained.
- Bundled Python/Qt and a prerequisite checker. Microsoft Visual C++ v14 Redistributable x64 14.44.35211.0 or newer is required.

## Download, install and update

Download the complete `MediaOrganizer-a.0.4.5-windows-x64.zip`, its SHA-256 file, and the release manifest/signature when published. Extract into a new folder and retain the complete folder structure. Run `Apps/collectigen.media-organizer/0.4.5-alpha.1/Start_MediaOrganizer.bat`. No separate Python is needed. Read the included README and TESTING documents.

Use copied media and a separate evaluation profile. The launcher accepts `--profile-root` for an explicit profile directory. Keep older packages and profile/data backups. Updating means extracting a new complete package into a separate folder; automatic or in-place update and cross-version profile migration are not qualified. Do not mix DLLs or overwrite an existing installation.

The source companion `MediaOrganizer-a.0.4.5-source-notices.zip` and `SOURCE_DELIVERY_SUPPLEMENT.md` belong to this exact binary. They provide matching application source, third-party notices and Qt/PySide source delivery and private replacement guidance. Consult included license scope and resource notices; incorporated resources retain their own terms.

## Limits

Active Manager inheritance/launch, cross-app reconciliation, Encyclopedia integration, automatic updates, AI/model execution, video/audio, training and generation are unfinished or outside this package's qualified scope. Optional AI controls do not establish installed capability. No models are bundled. Linux, clean-machine installation and all-profile/large-library coverage are not claimed. A detached release signature is not Windows Authenticode signing.
