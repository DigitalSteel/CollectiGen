# Try Media Organizer a.0.4.5 safely

Use a few copied images, a separate test profile and a backup of any existing work. Leave your only originals and private libraries out of evaluation.

1. Start through **Start_MediaOrganizer.bat** and choose incoming/library folders in Setup. Save Storage Folders, then open Ingest and confirm the incoming folder matches your choice.
2. Open an image through the normal visible editor. Manually review its Tags, Descriptions, content rating and remaining readiness guidance. Save, then reopen it and confirm the saved values and JSON/TXT sidecars agree.
3. Select a named library destination and review its sharing boundary. Preview the move. If required knowledge is missing, keep the image held and correct it rather than bypassing readiness.
4. Move one ready copied image. Confirm the image and sidecars are at the chosen destination and that the incoming copy is no longer there.
5. Choose Open in Dataset and inspect the same image. Let the gallery settle; confirm the saved Tags/Descriptions and library identity. Close normally and allow work to drain.

Try Cancel only within the test-copy workflow and confirm it retains the expected work. Do not simulate power loss, corrupt a real profile, delete caches, or force-stop a pending move to test recovery. If an operation remains held, preserve the files and diagnostic and report it.

For a useful report, note the exact version, Windows version, visible steps, expected result and actual result. Review every attachment; omit private media, Local Only material, credentials and unredacted paths/logs. See [support](SUPPORT.md). Security vulnerabilities use the [private route](SECURITY.md).

For this candidate, check the four setup categories, optional AI/no-download default, saved preferences and Save and Continue Later. Finish should return without automatically opening or scanning a library. Close normally before testing a separate profile.
