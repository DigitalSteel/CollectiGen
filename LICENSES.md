This file explains which license applies to each part of CollectiGen. It does not replace any license text or grant rights in material the project does not own.

Third-party libraries, copied code, generated bindings, tools, and runtime components are not relicensed by this statement. They retain the terms identified in [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md), the portable package's generated `THIRD_PARTY_COMPONENTS.json`, their accompanying notices, and [`licenses/`](licenses/).

## Original documentation and compiled knowledge

Original CollectiGen prose, diagrams, and the original copyrightable selection, organization, and additions in compiled System Knowledge are licensed under **Creative Commons Attribution-ShareAlike 4.0 International** (`CC-BY-SA-4.0`). The complete license is in [`licenses/CC-BY-SA-4.0.txt`](licenses/CC-BY-SA-4.0.txt).

That license covers only rights the CollectiGen project can grant. Facts, names, user additions, quoted or incorporated third-party material, upstream datasets, and separately licensed source material retain their own status and terms. Source-specific provenance and attribution remain required.

## Optional models and user data

Optional model weights are not bundled and retain their own terms. In particular, JoyCaption's source repository uses Apache-2.0, while the supported JoyCaption model uses the separate Llama 3.1 Community License and Acceptable Use Policy; the model is not described as OSI open source. The optional Florence-2 Base FT checkpoint is identified as MIT-licensed and remains an unbundled, exact-revision download. See [`licenses/Llama-3.1-Community.txt`](licenses/Llama-3.1-Community.txt) and [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

Images, Image Knowledge, prompts, Metadata, private libraries, settings, support bundles, and other user-owned content are not relicensed merely because CollectiGen reads, writes, indexes, exports, or backs them up.

No project license grants rights to the CollectiGen name, logo, or other trademarks beyond reasonable use necessary to identify the software and comply with attribution requirements.
