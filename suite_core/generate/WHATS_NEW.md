# CollectiGen Generate 0.1.1-alpha.1

November 18, 2026 · Alpha

- Preserve exact whole seeds written in decimal or exponent notation, including
  JSON numbers, seed strings and infotext variation seeds. New reads keep those
  values exact in the display and saved record.
- Use Manager 0.8.0-alpha.1 with launcher 0.1.1 to review and confirm the
  update from Generate 0.1.0-alpha.1.

## Previous alpha

November 17, 2026 · Alpha

- Generate has its own application window, installed and opened from Suite
  Manager's Applications section.
- Create image and video requests, save drafts and reopen your work. Closing a
  modified image request saves it and finishes the normal Close operation.
- Existing requests, resources and saved work remain in the Suite workspace.
  Manager waits for the workflow to finish before allowing shared changes.
- Manager handles installation, updates, shared settings and connections.
  Updates and restarts remain explicit choices.

Use Manager 0.8.0-alpha.1 with launcher 0.1.1 from the complete Suite distribution.
See README.md for startup and recovery guidance. Compatible backend resources
are still required. Real model execution, output quality and video generation
have not been qualified by the synthetic workflow checks for this release.
