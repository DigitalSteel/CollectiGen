# Media Organizer support

This is an unpublished alpha evaluation candidate. There is no paid support, guaranteed response time, compatibility guarantee or guaranteed data recovery. Use copied media and backups. Best-effort public alpha support targets the latest public prerelease when one exists.

Use the project's [GitHub Issues](https://github.com/DigitalSteel/CollectiGen/issues) for non-sensitive reports. Give the exact version, Windows version, visible steps, expected behavior and actual behavior. Search existing reports first. Do not assume a source commit is a new executable release.

Review screenshots, logs and attachments before posting. Exclude private images, Local Only material, names/paths, credentials and unredacted diagnostics. A text-only report is useful. Do not publicly attach unblurred Questionable or Explicit content. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

The application does not submit reports or upload attachments automatically. Opening a website is your own network action. Start with the [README](README.md), [user guide](docs/USER_GUIDE.md) and [testing checklist](TESTING.md).
